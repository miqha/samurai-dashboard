КАК ЧИТАТЬ ИНТЕРВАЛЫ

Ширина — это неопределённость

Интервал оценивает средний перфоманс для группы, а не разброс будущих игр. При одной игре интервал не рассчитываем; для 1–2 участников без игр сохраняем пустые строки.

Приближённый 95% ДИ построен по распределению Стьюдента на уровне турниров, с предположением независимых наблюдений. Малые и похожие по времени выборки требуют осторожности: повторяющиеся составы и разные сезоны ограничивают интерпретацию.

ВСЕ РАЗМЕРЫ ЗАЯВКИ

Цифры рядом с графиком

Средние и интервалы используют игры с известным перфомансом. Покрытие — доля таких игр среди заявок данного размера. Стандартное отклонение описывает разброс отдельных результатов.

Авторы и редакторы — разные роли. Для авторских групп используем только явно указанные в источнике диапазоны вопросов; для редакторов — результаты всего пакета.
