# Самурайская самоизоляция · Додзё статистики

## GitHub Pages с автообновлением

Для загрузки целой папкой подготовлена отдельная копия **`samurai-dashboard-github`**. В ней уже есть Actions для обновления всех данных каждые шесть часов и публикации Pages, безопасный начальный снимок и режим кнопки обновления для статического сайта. Загрузите содержимое папки в корень репозитория, включите Pages → GitHub Actions и запустите workflow. Подробные шаги — в [GITHUB-PAGES.md](GITHUB-PAGES.md).

Из чистой копии сначала запустите локальный запуск для своей системы: он восстановит встроенный снимок и создаст автономный HTML. Следующие разделы описывают локальный режим; поведение опубликованного сайта описано в инструкции GitHub Pages.

## Как открыть

**Для обновления из страницы дважды нажмите `start-dashboard.command` на macOS или `start-dashboard.cmd` на Windows.** Нужны Python 3.10+ и интернет. Откроется браузер с локальным дашбордом; оставьте окно запуска открытым. Для остановки нажмите в нём Ctrl+C.

Кнопка **«Обновить данные»** вверху страницы запускает полное обновление: историю выступлений и ответы, сложность пакетов, пересечения вопросов, авторские группы, каталог турниров и заявки, связи GotQuestions, тренировочную базу и типы вопросов. На странице виден текущий этап. После проверки новых данных сохраняется также автономный HTML, а страница сама перезагружается. Повторные нажатия не создают второе обновление. Если источник недоступен или данные неполные, остаётся прежний снимок.

При обычном открытии HTML двойным щелчком браузер не может запускать Python. Кнопка подскажет, как открыть локальный режим. Достаточно открыть локальный запуск для своей системы один раз на время работы с дашбордом; дальнейшие обновления запускаются кнопкой.

Независимые источники обновляются параллельно. Повторные обращения к одним данным в пределах обновления исключены, пакеты загружаются в сжатом виде и повторно проверяются условным HTTP-запросом, если источник выдал ETag или Last-Modified. Старая запись без подтверждения источника не считается свежей. Запросы ограничены по частоте; при ограничении GotQuestions обновление останавливается и сохраняет срок ожидания перед новым запуском. Во время загрузки можно пользоваться прежней статистикой.

В этом режиме раздел **«Что сыграть»** проверяет публичный каталог при открытии страницы и затем каждые 15 минут, пока вкладка видима; при возвращении на вкладку источник проверяется снова. Начало и окончание окон отыгрыша пересчитываются по текущему времени. На странице видны дата проверки и состояние источника; если обновление не удалось, остаётся последний успешный снимок с предупреждением.

**Для просмотра статистики и текстов без запуска и без интернета откройте `samurai-dashboard.html`.** Все стили, графики и сохранённые данные встроены в один файл; его можно переносить отдельно. В автономном режиме часы устройства скрывают истёкшие окна и открывают наступившие окна из снимка. Новые турниры и изменения сроков появятся после обновления через локальный запуск или повторную сборку файла.

`index.html` — версия с раздельными исходными файлами. Для неё сохраняйте всю папку целиком. Альтернатива двойному щелчку: из этой папки выполните `python3 scripts/serve.py --open`.

## Windows: запуск и передача папки

Передайте **всю папку `samurai-dashboard` целиком** и распакуйте её в доступное для записи место, например «Документы». На Windows 10/11 нужны **Python 3.10 или новее** и интернет для обновления. Сторонние библиотеки, Node.js и отдельная база часовых поясов не требуются. Python не устанавливается автоматически; если его нет, окно запуска покажет ссылку на официальный установщик. При установке включите Python Launcher или «Add python.exe to PATH».

- Дважды нажмите **`start-dashboard.cmd`**: откроется локальная страница с рабочей кнопкой **«Обновить данные»**. Оставьте окно запуска открытым, завершение — Ctrl+C.
- Дважды нажмите **`update-dashboard.cmd`**, чтобы сразу выполнить полное обновление без запуска страницы. После успешного завершения откройте `samurai-dashboard.html`.
- **`samurai-dashboard.html`** открывается для автономного просмотра без Python; для обновления нужны скрипты и данные из всей папки.

Запуск не зависит от буквы диска, пробелов и кириллицы в пути: используется папка самого файла. Сначала проверяется `py -3`, затем `python`; устаревшая версия не подходит. Русский вывод и журнал `.updates/windows-launch.log` сохраняются в UTF-8. После завершения окно ждёт нажатия клавиши, чтобы результат или ошибку можно было прочитать. Подробный отчёт неудачного обновления находится также в `.updates/last-error.json`. Для даты обновления используется московское время UTC+3, включая Windows без IANA tzdata. Исторические даты сохраняют исходные часовые смещения.

Проверки запуска и переносимости выполнены автоматически на macOS; запуск в настоящей Windows в этой среде не проверялся. Передавать `.updates` с прежними журналами необязательно. История тренировок хранится отдельно в браузере каждого получателя и не переносится вместе с папкой.

## Что можно посмотреть

- **Что сыграть** — турниры с открытым окном проведения, соответствие уровню команды, прогноз взятий, сроки и ссылки на организаторов; отдельно будущие окна и турниры из заявок команды. По умолчанию «по уровню» означает ориентир на 30–65% взятий, а не оценку качества пакета.
- **Обзор и турниры** — динамика перфоманса B, среднее и медиана, карта результатов и таблица с поиском и сортировкой. Нажмите на точку или строку для маски ответов, состава и распределения результатов соперников.
- **Вопросы** — результаты при разной фактической сложности турнира trueDL, взятие по номеру в пакете или туре, цветная матрица истории, редкие взятия и потери на доступных вопросах.
- **Игроки** — выбор года, заявленные составы, результаты команды при участии игрока, совместные выступления и граф связей. Кнопка «Только участники с 10+ играми» скрывает редких участников в таблице, графиках и парах. Порог считается в выбранном году, формате и срезе; ровно 10 игр уже достаточно.
- **Моя статистика** — выберите своё имя из всех опубликованных составов: динамика B, последние пять игр против предыдущих пяти, лучший турнир, разрезы по годам и форматам, тиммейты с числом совместных игр и 95% ДИ, полный архив отыгрышей. Имя запоминается в этом браузере, если доступно локальное хранилище. Год можно выбрать прямо в личной вкладке. Здесь только выступления за «Самурайскую самоизоляцию».
- **Размер состава** — средний перфоманс B по числу участников, 95% доверительные интервалы, отдельные турниры и таблица с числом игр, медианой, разбросом и покрытием. Точки игр открывают разбор; их можно скрыть.
- **Авторы и редакторы** — сравнение явно указанных авторских групп диапазонов и редакторов пакетов.
- **Инсайды** — наблюдения, которые пересчитываются для выбранного среза.

Фильтры года, формата и игрока действуют на историческую статистику вместе, включая размер состава. Рекомендации калибруются по недавним играм всей команды. Наводите курсор на графики: подсказки показывают значения и объём выборки. Кнопка **«Экспорт»** сохраняет текущий список в CSV для Excel: во вкладке «Что сыграть» — все отфильтрованные рекомендации, в исторических разделах — сыгранные турниры выбранного среза с отдельной колонкой «Перфоманс B». Кодировка UTF-8, разделитель `;`.

## Перфоманс и размер состава

По выбранному командой определению **перфоманс — турнирный балл B**, колонка «Рейтинг» в результатах, поле `rating.b` публичного API. Это не входной рейтинг состава и не изменение рейтинга. Среднее и медиана считаются по турнирам с известным B, с одинаковым весом каждой игры. Нулевой B и рассчитанный B без зачисления бонуса (`inRating=false`) учитываются; пропуски не превращаются в нули.

B учитывает место, делёж мест и силу игрового поля. **TrueDL напрямую в формулу B не входит.** Определение и формулы проверены по [официальным документам](https://rating.chgk.info/documents) и Положению о рейтинговании. Каталог [awesome-chgk](https://github.com/gltronred/awesome-chgk) добавлен в источники на странице.

Основные сравнения выступлений, игроков, пар и редакторов используют B. Проценты взятия сохранены для вопросов, туров, авторских диапазонов и регрессии по trueDL. Балл всей игры нельзя приписать части пакета.

В разделе «Размер состава» группа — число разных участников в опубликованном составе за турнир. Состав может включать замены, поэтому семь участников не означают одновременную игру всемером. Группы 1–2 не имеют наблюдений на текущем снимке и остаются пустыми.

Личная вкладка описывает результат всей команды при участии выбранного игрока. Индивидуальные ответы и личный причинный вклад источник не раскрывает. Тиммейты ранжируются по среднему B в общих играх; по умолчанию нужны минимум три совместных турнира с известным B. Можно показать и партнёров с одной игрой, но их выборка отмечена как малая. Изменение формы появляется только при наличии двух полных непересекающихся окон по пять игр с B. Экспорт в личной вкладке содержит только отыгрыши выбранного игрока за выбранный период и формат.

95% ДИ среднего рассчитан по турнирам: `mean ± t(0.975, n−1) × sample_SD / √n`. При `n<2` интервал отсутствует. Это приближённый интервал при предположении независимых наблюдений и применимости t-приближения. Он не прогнозирует следующую игру и не доказывает причинный эффект дополнительного игрока. Малые составы чаще встречаются в ранней истории: сравнивайте также отдельные годы и форматы.

## Вопросы и таблицы

В списках **«Редкие взятия»** и **«Обидные потери»** можно независимо выбрать минимум **10** или **30** команд. Учитываются команды с известным ответом на конкретный вопрос, включая нашу; взятие поля по-прежнему считается без нашей команды. Ограничения применяются к этим двум спискам. Все подходящие вопросы доступны в прокручиваемых таблицах.

Все таблицы поддерживают единый цикл нажатий заголовка: **возрастание → убывание → исходный порядок**. Пропуски остаются внизу, равные значения сохраняют исходный взаимный порядок. Даты и числа сортируются по значениям; доверительные интервалы — по нижней границе. Работают клавиатура и озвучивание направления сортировки.

## Тренировки

Банк охватывает полный публичный каталог за последние 12 месяцев по фильтру GotQuestions «Сыграно от/до». Точные даты, число вопросов, пакетов и авторов показаны на странице и пересчитываются при обновлении. Выберите автора (список отсортирован по фамилии), формат, пакетную сложность **trueDL**, допустимое отклонение и число вопросов. При включении «Все сложности» доступны также вопросы без trueDL. Три неполные записи источника сохранены в архиве, но не предлагаются в тренировке. Для иллюстраций и аудио нужен интернет; тексты и ответы встроены в HTML. Подборка случайная; ранее сыгранные в тренировках вопросы можно исключить. Если подходящих вопросов меньше запрошенного, интерфейс заранее показывает фактический размер подборки. Полнота банка сверена с каталогом источника и количеством вопросов каждого пакета. При нескольких trueDL используется исходное значение турнира с наибольшим полем, а все остальные значения сохранены в данных.

Сначала открывается текст вопроса и раздатка; время чтения не ограничено. **Таймер начинает идти только после кнопки «Начать отсчёт»**, включая каждый следующий вопрос. После нажатия — **60 секунд**: одиночный сигнал на **50-й**, двойной на **60-й**, затем **10 секунд на сдачу**. Черновик автоматически фиксируется на 70-й секунде. Можно сдать раньше, поставить паузу, пропустить вопрос или завершить подход. Следующий вопрос открывается отдельной кнопкой и снова ждёт запуска отсчёта. Запущенный таймер учитывает реальное время, включая уход с вкладки; чтение до запуска и паузы исключаются. Для проверки звука есть кнопка до старта.

После финиша нажмите **«Посмотреть результаты»**. Появятся ваши ответы, опубликованные ответы и комментарии, графики времени, результатов по пакетам и истории тренировок, авторская статистика и инсайты. Автоматически засчитываются только точные совпадения после нормализации регистра, пробелов, «ё/е» и завершающей пунктуации. Другие версии остаются на проверке: зачёт выставляете вы. Доля взятия считается среди оценённых ответов; несыгранные и неоценённые показаны отдельно.

Сессия восстанавливается после перезагрузки; последние 12 тренировок сохраняются локально в этом браузере. Можно скачать результаты в JSON. Сравнение с прошлым требует трёх полностью оценённых подходов с тем же фильтром автора, не менее трёх сыгранных вопросов и близким средним trueDL (±0,5). Это описательная статистика практики; официальный турнирный балл B здесь не рассчитывается.

## Работа над ошибками выбранной игры

Блок есть во вкладках **«Тренировки»** и **«Фокус команды»**. В выпадающем списке объединены три последних сыгранных турнира с точным сопоставлением вопросов GotQuestions и три сыгранных турнира с самыми свежими публикациями пакетов. Совпадающие турниры показаны один раз: обычно получается от трёх до шести вариантов, при малом срезе — меньше. По умолчанию выбрана последняя сопоставленная игра. При смене турнира меняются B, разбор категорий, исходные пропуски и подбор тренировки; выбор сохраняется при переходе между этими двумя вкладками. Более новые несопоставленные турниры отмечены отдельно. Игры упорядочены по началу официального окна; источник не знает фактический день отыгрыша команды. Порядок публикаций определяется настоящим `pubDate` пакета GotQuestions, а не датой загрузки. У выбранного турнира показана дата публикации; неизвестные даты не подменяются и не участвуют в отборе свежих публикаций.

Категории — доля взятия вопроса полем, дуплеты/блицы и другие форматы, формы ответа и раздатка. На каждом вопросе нужны 30 известных ответов соперников. Приоритет — категория с пропусками, отрицательной разницей с полем и хотя бы тремя вопросами; группы менее пяти отмечены как малые. Ранжирование по сумме `доля поля − наш результат` помогает выбрать материал, но не оценивает устойчивую слабость. Если отрицательных разрывов нет, показана возможность закрепить успешные категории.

**«Тренировать категорию»** предлагает до 10 новых вопросов строго той же категории. Для сложности используются попарно проверенные опубликованные `correctAnswers / teamsCount` GotQuestions, минимум 30 команд; при нескольких наблюдениях берётся наибольшее поле. Сила и состав поля могут отличаться от исходной игры. TrueDL не подменяет сложность отдельного вопроса. Форматы и формы определяет общий классификатор по явным инструкциям; у него возможны пропуски нетипичных формулировок.

Подтверждённые сыгранные ID вопросов, пакеты и связи с отыгранными турнирами исключены. Из несопоставленных игр возможны неизвестные повторы. При нехватке вопросов условия не расширяются: показано фактически доступное число. В итогах тренировки сохранены исходный турнир и категория; новые проценты не объявляются изменением перфоманса B. Незавершённый подход не заменяется новой подборкой.

## Фокус команды

Новый раздел превращает историю игр в материал для следующей тренировки:

- **Карта изменений:** сравнение двух непересекающихся отрезков по 5–10 турниров. Для каждого диапазона сложности показаны взятие команды, взятие поля на тех же вопросах и размеры выборок; рядом — средний официальный B. Первым открывается диапазон с самым заметным наблюдаемым изменением.
- **Доступные потери:** вопросы, взятые минимум 60% соперников при 30+ известных ответах поля. Можно разбирать по авторам, формам, форматам и раздаткам, раскрывать исходные игры и создавать подборку вопросов этих авторов. В подборке исключены подтверждённые сыгранные вопросы и пакеты. Приём или тема тренировки могут отличаться от исходных потерь.
- **Ритм тура:** сравнение первой и последней трети на доступных вопросах с отдельными долями поля и знаменателями.
- **Коллекция редких взятий:** конкретные вопросы для командного разбора удачных решений.

Фильтры истории действуют на весь раздел. Пропуски GotQuestions и малые выборки показаны явно; оценки индивидуального вклада отсутствуют. Все разборы считаются из текущего снимка при открытии, поэтому включены в общий цикл обновления. Уже начатая тренировка сохраняется при выборе нового фокуса.

## Тренировки по заявке и типы вопросов

В тренировках выберите турнир из **заявок команды**. Для опубликованного пакета берутся авторы его вопросов; для неопубликованного явно предлагаются прошлые авторские вопросы объявленных редакторов. Видны совпавшие люди и число доступных вопросов; целевой пакет исключается. По умолчанию доступны текущие и будущие заявки, отдельный переключатель открывает исторические.

Во вкладке **«Вопросы»** есть раздатки, обычные вопросы, дуплеты, блицы, тетраблицы и признаки формы ответа: одинаковые гласные, парные согласные, одинаковые или соседние начальные буквы, окончания, рифмы и другие. Поле и команда сравниваются на одних вопросах с одинаковым весом каждого вопроса. Нажатие категории открывает проверяемые признаки и ссылки. Категории формы могут пересекаться; отсутствие найденного признака не доказывает отсутствие ограничения. Охват и несопоставленные турниры показаны в интерфейсе.

**«Обновить данные»** выполняет все 10 этапов: результаты/B/составы/маски, сложность, пересечения, титры, каталог и заявки, связи GotQuestions, годовую базу, типы сыгранных вопросов, авторов заявок и автономный HTML. Публикуется только согласованный снимок; при ошибке прежний сохраняется. Локальные результаты тренировок остаются в браузере.

## Как читать рекомендации и GotQuestions

Открытый срок проведения **не подтверждает наличие площадки, свободных мест или допуск команды**. Проверяйте дедлайн заявки и правила по ссылке организатора. Уже сыгранные турниры и регистрации исключаются по сохранённой истории и проверяемому вместе с каталогом списку регистраций команды. Официально отмеченные пересечения вопросов и общие ID пакетов также учитываются: синхрон и асинхрон могут иметь разные ID и общие вопросы. Похожее название отмечается как возможный повтор и не попадает в основной список рекомендаций.

GotQuestions и Rating используют **шкалу фактической сложности trueDL от 0 до 10: больше — сложнее**. Значения получены из [официального API Rating](https://api.rating.chgk.info/docs.jsonopenapi); общую шкалу подтверждает [автор trueDL](https://code.pecheny.me/pecheny/truedl). Это сложность турнира, а не пользовательский рейтинг качества и не оценка каждого вопроса. Прогноз организаторов (`difficultyForecast`) показан отдельно и калибруется отдельно от фактического trueDL.

В исходном снимке от 7 ноября для 52 из 54 сыгранных турниров был trueDL; среди всех 57 карточек — 53 значения. Текущий охват показан на странице. Для 20 турниров были получены точные ссылки на пакеты GotQuestions через официальный `gotQuestionsTags`. Историческая проверка 7 ноября получила HTTP 429; последующие публичные запросы успешны. Текущие статусы и даты сохранены в данных источников. trueDL относится к целому пакету. Для отдельных вопросов используется фактическая доля взятия остальными командами турнира; типы и формы вопросов берутся из опубликованных текстов GotQuestions.

Прогноз — эмпирический ориентир по последним 24 подходящим опубликованным играм. Он не гарантирует результат; вне изученного диапазона сложности неопределённость выше. Подробнее — **«Источники и методика»** внутри страницы и `README-data.md`.

## Какие данные сохранены

Исходный снимок истории команды №**100321**, Санкт-Петербург, загружен **7 ноября 2026 в 16:05 по Москве**: **54 опубликованных выступления, 2258 действительных вопросов, 868 взятий и 28 игроков в заявках**. Из 57 регистраций исключены один будущий турнир и два без опубликованного результата. В расчётах исключены 4 снятых вопроса. В исходном снимке дата отсечения — 07.11.2026. После обновления актуальная дата и охват показаны на самой странице; даты турниров обозначают начало общего окна, а не обязательно день игры команды.

Каталог доступных турниров имеет собственную дату загрузки, показанную в разделе «Что сыграть». При обновлении проверяется также список ID регистраций команды. Кнопка **«Обновить каталог»** проверяет календарь и согласует с ним связи GotQuestions и подборки по заявкам. После новых игр и поздних апелляций нажмите общую кнопку **«Обновить данные»**: она обновит и историю, и метаданные; модель будет пересчитана при автоматической перезагрузке страницы.

Источник — [карточка команды rating.chgk.info](https://rating.chgk.info/team/100321) и [публичный API](https://api.rating.chgk.info/index.html?ui=re_doc). Указанный адрес `rating.chgk.org` при первой сборке не разрешался. Отдельный студенческий зачёт не выделен. Исторические частоты поля считаются без нашей команды.

Статистика игроков описывает результат всей команды при наличии человека в заявке; источник не сообщает личные ответы и время за столом. В исходном снимке авторские титры покрывали 580 из 2258 действительных вопросов, или 25.7% истории: группы диапазонов не устанавливают автора отдельного вопроса. Редакторы пакетов показаны отдельно.

## Как обновить историю и автономный файл

Откройте `start-dashboard.command` и нажмите **«Обновить данные»**. Дата отсечения выбирается по текущему дню в Москве. Для ручного запуска той же проверяемой последовательности из этой папки выполните `python3 scripts/update_dashboard.py`.

Отдельные шаги для диагностики можно выполнить по порядку. Дата в первой команде задаёт новый срез истории; замените её нужной календарной датой.

```sh
python3 scripts/fetch_data.py --refresh --cutoff 2026-11-11
python3 scripts/fetch_team_difficulty.py --refresh
python3 scripts/fetch_team_intersections.py --refresh
python3 scripts/fetch_authors.py
python3 scripts/fetch_catalog.py
python3 scripts/fetch_gotquestions.py --catalog data/catalog.json --probe-homepage --refresh-probe
python3 scripts/fetch_training.py --refresh-year
python3 scripts/fetch_played_questions.py --refresh
python3 scripts/fetch_registration_authors.py --refresh
python3 scripts/build_standalone.py
```

Затем перезагрузите страницу. Загрузчики используют стандартную библиотеку Python. Обновление перепроверяет все пакеты годового каталога; при HTTP 304 использует только проверенную сохранённую запись. Полный проход может занять несколько минут; длительности этапов сохраняются в результате обновления. Без `--refresh` исторические загрузчики используют сохранённые записи; дата отсечения `fetch_data.py` по умолчанию остаётся **2026-11-07**.

`data/raw/` содержит компактные проверяемые ответы источника с URL и временем загрузки. `data/dashboard.json` и `data.js` — история команды; `data/catalog.json` — каталог; `data/team-difficulty.json` — trueDL и ссылки на пакеты; `data/team-intersections.json` — официальные пересечения вопросов; `data/gotquestions.json` — аудит источников GotQuestions. История, каталог, метаданные сложности и пересечения вопросов включаются в автономную сборку.

Автоматические проверки при установленном Node.js:

```sh
node tests/test_analytics.js
node tests/test_performance.js
node tests/test_roster_stats.js
node tests/test_personal_stats.js
node tests/test_table_sort.js
node tests/test_training.js
node tests/test_training_ui.js
node tests/test_dashboard.js
node tests/test_recommendations.js
node tests/test_planner_ui.js
node tests/test_update_ui.js
python3 -m unittest discover -s tests -p test_live_catalog.py
python3 -m unittest discover -s tests -p 'test_update*.py'
```

Графики используют локальную **Apache ECharts**, лицензия — `vendor/ECHARTS-LICENSE.txt`. Автономный файл содержит ресурсы внутри; локальный режим дополнительно обращается к публичному Rating API через сервер в этой папке.
