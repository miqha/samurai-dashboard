# Проверка ускорения обновления

Из папки дашборда: `python3 scripts/benchmark_update.py` (Windows: `py -3 scripts/benchmark_update.py`).

Интернет не используется, данные сайта не изменяются. Старый планировщик сохранён в `baseline/update_dashboard.py` как тестовый образец; запускать его отдельно для обновления не нужно. Публичные записи для обоих вариантов одинаковы и сохранены в `.checks/update-benchmark-inputs.zip`. Хеши записей, условия и измерения находятся в `.checks/update-benchmark.json`.

Сетевой профиль: задержка 0,25 секунды, 1 МБ/с на соединение. Сетевое время и паузы уменьшены в 50 раз, чтобы проверка занимала секунды; разбор данных, подготовка снимка и проверки выполняются с обычной скоростью. Проверяется совпадение всех разобранных записей. Измеренное ускорение относится к этому воспроизведению; время настоящего обновления зависит от интернета и источников. Условные ответы 304 в измерении не используются.

`--capture-current` заменяет входные записи текущим сохранённым снимком для новой проверки. `--scale 1` оставляет сетевые паузы профиля без уменьшения. Проверка работает и в Windows без tzdata: при загрузке старого образца только привязка московского часового пояса заменяется на переносимый UTC+3. Исходный файл и его контрольная сумма сохраняются без изменений; эта адаптация отдельно указана в отчёте.
